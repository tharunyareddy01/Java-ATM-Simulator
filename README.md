# Java ATM Simulator

A simple ATM Management System project developed using Java.

## Features
- PIN Authentication
- Check Balance
- Deposit Amount
- Withdraw Amount
- Menu Driven Program

## Technologies Used
- Java
- VS Code

## Concepts Used
- OOP (Object Oriented Programming)
- Classes and Objects
- Methods
- Scanner Class
- Switch Case
